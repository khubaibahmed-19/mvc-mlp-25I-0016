# mvc-mlp-[yourrollno]

A manual implementation of a Multilayer Perceptron (MLP) trained on the MNIST dataset.
Built from scratch using NumPy only as part of the MVC Project for Artificial Neural Networks.

## How to Run

1. Go to https://colab.research.google.com
2. Click **File → Upload Notebook** and upload `src/mvc_mlp_task7.ipynb`
3. Run all cells in order (Cell 1 to Cell 14)
4. The MNIST dataset will download automatically when Cell 2 runs

## Repository Structure

src/      - Jupyter Notebook (.ipynb)
data/     - MNIST dataset (mnist.npz)
report/   - PDF report compiled from LaTeX on Overleaf
README.md - This file
